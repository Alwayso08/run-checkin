## 这个小程序能做什么

- 每天收到一条**微信服务通知**提醒打卡（个人小程序限制：每天点一次"订阅"按钮，才能收到下一天的提醒）
- 固定入口：微信下拉或在"最近使用的小程序"里找到它，随时打开打卡页
- 设置每周目标天数和提醒时间
- 打卡数据仍保存在打卡网页 https://run-checkin.pages.dev 里，小程序只做提醒和入口

## 第 1 步：安装微信开发者工具

1. 电脑打开 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载 **稳定版 Stable Build → Windows 64 位**
3. 安装并打开，用**管理员微信扫码登录**（就是你注册小程序时的微信）

## 第 2 步：导入项目

1. 开发者工具里点 **+ 导入项目**
2. 目录选择：`C:\Users\Alwayso\Downloads\软件设计\小程序-checkin` 文件夹（注意是项目根目录，里面有 project.config.json）
3. AppID 会自动填入 wx1891b75643fa0440 → 点**导入**
4. 看到模拟器里出现深色"跑步打卡"页面就说明导入成功

## 第 3 步：开通云开发（用来定时发提醒）

1. 开发者工具左上角点 **云开发** 按钮
2. 按提示**开通**（选择免费套餐/基础套餐，0 元）
3. 创建一个环境（名字随便，如 runcheckin）→ 创建完成后注意看**环境ID**（形如 cloud1-xxxxx）

## 第 4 步：把环境ID填进代码

1. 打开 `miniprogram/app.js`
2. 找到 `cloudEnvId: ''`
3. 把环境ID填进去，变成 `cloudEnvId: 'cloud1-xxxxx'`
4. 保存（Ctrl+S）

## 第 5 步：部署云函数

1. 在开发者工具左侧资源管理器里，找到 `cloudfunctions` 文件夹
2. 右键 **sendReminder** → **上传并部署：云端安装依赖**
3. 同样右键 **saveSubscription** → **上传并部署：云端安装依赖**
4. 稍等片刻，提示上传成功即可

## 第 6 步：配置订阅消息模板

1. 电脑浏览器登录小程序后台 https://mp.weixin.qq.com
2. 左侧 **功能 → 订阅消息**
3. 点 **添加模板** → 在公共模板库里搜索「**打卡**」或「**提醒**」
4. 选用一个合适的模板（字段通常是：提醒事项/时间/备注之类）→ 记下 **模板ID**
5. 把模板ID填到两处：
   - `miniprogram/app.js` → `tmplId: '模板ID'`
   - `cloudfunctions/sendReminder/index.js` → 顶部 `const TMPL_ID = '模板ID'`
6. 按模板实际字段名修改 `sendReminder/index.js` 里 `buildTemplateData()` 的字段（thing1/time2/thing3 等，以模板详情页显示的字段名为准）
7. 重新右键 sendReminder → **上传并部署**

> 如果个人主体在模板库里搜不到合适的模板，把你能看到的模板名字告诉我，我帮你挑。

## 第 7 步：上传体验版先测试

1. 开发者工具右上角点 **上传**
2. 版本号填 1.0.0，备注随便写 → 上传
3. 回到小程序后台 → 管理 → 版本管理 → 开发版本里能看到刚上传的版本 → **选为体验版**
4. 用微信扫体验二维码，在手机上体验：点"订阅明天的提醒"→ 明天到点应收到服务通知

## 第 8 步：备案通过后正式发布

1. 小程序后台确认备案状态为「已备案」
2. 版本管理 → 开发版本 → **提交审核**（类目选择：工具-效率 或 体育）
3. 审核通过后 → **发布**
4. 完成！微信里就能正式使用

## 常见问题

| 问题 | 解决 |
|---|---|
| 导入后模拟器白屏 | 检查是否选中了项目根目录（有 project.config.json 的那层） |
| 云函数上传失败 | 开发者工具里重新登录；或检查网络 |
| 收不到提醒 | ① 模板ID没填/字段名不对 ② 没点"订阅" ③ 云函数没部署 ④ 提醒时间没到 |
| 模板搜不到 | 个人小程序类目有限，换关键词（提醒/打卡/运动/健康）搜，或告诉我截图文字 |
| 备案没过 | 按后台提示补充材料，通常 1~2 周重审 |

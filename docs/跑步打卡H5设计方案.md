# 🏃 跑步打卡 H5 · 产品与技术设计方案

> 单用户 · 微信内使用 · 纯本地存储 · 零服务器成本 · 移动端优先

## 一、已确认的需求（两轮问答结论）

| 问题 | 你的选择 |
|---|---|
| 使用范围 | 只有我自己用（无需登录注册） |
| 微信端形态 | 先 H5 网页，以后可升级小程序 |
| 服务器条件 | 没有服务器/域名，尽量简单低成本 |
| 跑步记录 | 距离、时长、配速等详细数据 |
| 面容记录 | 每天一张正面照 |
| 统计监督 | 体重曲线、跑步图表、照片时间线、微信提醒 |
| 数据存储 | 纯手机本地存储（零注册） |
| 跑步计划 | 自定义每周跑几天（如每周 4 天，哪天跑自己安排） |
| 微信提醒 | 愿意提前注册个人小程序（订阅消息提醒） |

## 二、总体方案

**阶段一（立即可用）：H5 单页应用**
- 一个手机网页，微信里点开即用，收藏 / 置顶到聊天里
- 数据全部存在手机本地（微信内置浏览器的本地存储），照片自动压缩后本地保存
- 部署到免费静态托管（推荐 GitHub Pages，无需服务器和域名）
- 内置"一键备份 / 恢复"，防止数据丢失

**阶段二（注册个人小程序后）：订阅消息提醒**
- 小程序只做一件事：每天定时微信推送打卡提醒（订阅消息）
- 点击提醒进入小程序，扫码 / 复制链接打开 H5 打卡页
- 打卡数据仍在 H5 本地，避免两处数据分裂

**阶段三（可选）：云端同步**
- 未来如想换手机不丢数据，可迁移到微信云开发（有免费额度），H5 与小程序共享同一份云端数据

## 三、功能设计

### 1. 今日页（首页）
- **今日状态卡**：一眼看出"今天该不该跑、跑了没"
  - 未跑：橙色警示"今天建议跑 🏃，本周还差 N 天达标"
  - 已跑：绿色完成态，展示今日距离 / 时长 / 配速
- **跑步打卡**：一键打卡弹窗，录入距离(km)、时长(分钟)、配速(min/km)，**输入任意两项自动算出第三项**；支持备注、编辑、撤销
- **体重打卡**：每天记录体重，输入即存，可随时改
- **正面自拍**：调起前置摄像头，屏幕上叠加"脸型对齐框"保证每天角度一致；自动压缩至约 150KB 存本地

### 2. 日历页
- 月历视图：跑步 ✓、体重 ⚖️、照片 📷 三类标记一目了然
- **连击天数**：连续打卡 N 天，断卡清零
- **周计划进度环**：本周已完成 X / 目标 Y 天

### 3. 统计页
- **体重曲线**：近 30 / 90 天折线图，可设目标体重参考线
- **跑步图表**：近 4 周 / 近 6 月切换，距离总量柱状图、时长与频次、平均配速趋势

### 4. 照片页
- 按月分组的照片时间线（3 列网格）
- 点开大图查看
- **双图对比**：任选两张（如第 1 天 vs 第 90 天），滑动分割线对比，直观看出面容变化

### 5. 我的页
- 每周目标天数（1~7）、体重目标设置
- **数据备份**：一键导出 zip（数据 + 全部照片），转发到"文件传输助手"保存；可随时导入恢复
- **打卡提醒设置**：生成提醒文案 → 发到文件传输助手 → 长按设置微信自带的"提醒"（阶段一过渡方案；小程序就绪后升级为订阅消息）

## 四、视觉设计

- **风格**：深色运动风，主色荧光绿渐变（#22C55E → #A3E635），警示橙（#FB923C）用于"该跑没跑"
- **布局**：移动端优先（最大宽度 480px 居中卡片），底部 5 个 Tab（今日 / 日历 / 统计 / 照片 / 我的）
- **状态色彩语义**：灰 = 未打卡，绿 = 已完成，橙 = 今日待跑
- **激励元素**：连击火焰 🔥、周进度环、达标动效

## 五、技术实现

- 纯前端三文件：`index.html` + `css/style.css` + `js/app.js`，无构建、无框架，改起来简单
- 图表库 Chart.js、打包库 JSZip 已内嵌到 `vendor/`，**不依赖 CDN**，微信内加载稳定
- 存储方案：
  - **localStorage**：打卡 / 体重 / 设置等结构化数据（体积小、读写快）
  - **IndexedDB**：照片 Blob（Canvas 压缩至 800px 宽 JPEG，约 100~200KB/张，一年约 40~70MB）
- 拍照：`<input type="file" accept="image/*" capture="user">`，微信内直接调起前置摄像头
- 备份：JSZip 打包 `data.json + photos/*.jpg` 导出 zip；导入时反向恢复

## 六、部署指引（阶段一）

1. 注册 GitHub 账号（免费）
2. 新建仓库，把本项目文件上传，开启 Pages（Settings → Pages → 选 main 分支保存）
3. 得到地址：`https://你的用户名.github.io/仓库名/`
4. 微信里打开该地址 → 右上角 "···" → 收藏；或转发到"文件传输助手"并置顶

> 备注：微信首次打开 github.io 链接可能提示"非微信官方网页"，点"继续访问"即可，之后一般不再提示。

## 七、风险与对策

| 风险 | 对策 |
|---|---|
| 微信清理缓存导致数据丢失 | 每周导出一次备份，发到文件传输助手留存 |
| 免费托管域名偶尔提示风险页 | 点"继续访问"；未来可绑定自有域名或迁国内托管 |
| 手机存储配额 | 照片已压缩；备份后可在设置中一键清理旧照片 |
| 个人小程序类目限制 | 阶段二注册后核实订阅消息可用模板；若受限则保留"微信自带提醒"方案 |

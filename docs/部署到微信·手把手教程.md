> 全程免费，不需要服务器、不需要懂代码。预计 15~20 分钟。

## 第 1 步（电脑）：把程序放到网上，拿到网址

这个文件就是整个程序，**不需要解压，不需要改任何东西**，稍后直接上传它。

**A2. 注册 Cloudflare 账号（2 分钟）**

1. 打开电脑浏览器（Edge/Chrome 都行），地址栏输入：`https://dash.cloudflare.com/sign-up` 回车
2. 页面中间：邮箱填你的邮箱 → 密码设置一个（**记下来，别忘**）→ 点 `Sign up`（注册）
3. 打开你的邮箱，找到 Cloudflare 发来的邮件，点里面的 `Verify Email`（验证邮箱）按钮
4. 验证后会自动登录进入后台（Dashboard）

**A3. 把界面换成中文（可选，界面是英文也不影响操作）**

1. 右上角点你的头像/人形图标 → 点 `My Profile`（我的个人资料）
2. 找到 `Preferences`（偏好设置）→ `Language`（语言）→ 选 `简体中文`
3. 刷新页面，界面就变中文了

**A4. 创建 Pages 项目（3 分钟）**

1. 左侧菜单找到 `Workers 和 Pages`（英文 `Workers & Pages`）点进去
2. 点页面中间的蓝色 `创建` 按钮（英文 `Create`）
3. 出现两个标签：选 `Pages` 标签
4. 点 `上传资产` / `直接上传`（英文 `Upload assets` / `Direct Upload`）
5. 项目名称（Project name）填：`run-checkin`（只能英文小写和横线）
6. 点 `创建项目`（`Create project`）

**A5. 上传部署包并发布（1 分钟）**

1. 进入项目页面后，把电脑上的 `跑步打卡-部署包.zip` **直接拖进上传区域**（或用"选择文件"按钮选它）
2. 点 `部署站点`（`Deploy site`）按钮
3. 等十几秒，显示绿色成功状态
4. 页面上会给出你的专属网址，形如：`https://run-checkin-xxxxx.pages.dev` ← **复制这个网址**

**A6. 电脑上先验证一下**

电脑浏览器打开刚复制的网址 → 能看到绿色的打卡页面、能点"今日打卡"弹出表单 → 成功！🎉

### 方案 B：GitHub Pages（备选：最经典、教程最多，但界面默认英文）

**B1. 注册 GitHub 账号**

1. 浏览器打开 `https://github.com` → 右上角 `Sign up`（注册）
2. 依次填：邮箱 → 密码 → 用户名（**英文小写**，比如 `alwayso-run`，起好记的）
3. 可能弹出人机验证：按提示做（比如输入图片里的字母、选出图片里的物体，慢点做就行）
4. 邮箱会收到 6~8 位验证码 → 回到页面输入 → 注册完成
5. 换中文界面（可选）：右上角头像 → `Settings` → 左侧找 `Language` → 选 `简体中文`。找不到就保持英文，下面的按钮名我都给了中英对照。

**B2. 新建仓库**

1. 登录后右上角点 `+` 号 → 点 `New repository`（新建仓库）
2. `Repository name`（仓库名）填：`run-checkin`
3. 选 `Public`（公开，免费的 Pages 只能用公开仓库）
4. 点最下面绿色 `Create repository`（创建仓库）

**B3. 上传程序文件**

1. 进入仓库页面后，点页面中间的蓝色文字 `uploading an existing file`（上传现有文件）
2. 打开电脑上的文件夹：`C:\Users\Alwayso\Downloads\软件设计\run-checkin`
3. 在文件夹里按 `Ctrl + A` 全选（会选中 index.html、README.md、css 文件夹、js 文件夹、vendor 文件夹 共 5 项）
4. 把这 5 项**全部拖进**网页中间的虚线框里
5. 等列表里所有文件都出现绿色对勾（上传完成）
6. 点最下面绿色 `Commit changes`（提交更改）

**B4. 开启 Pages 功能**

1. 自动回到仓库首页后，点顶部 `Settings`（设置）
2. 左侧菜单往下拉，点 `Pages`
3. 中间 `Build and deployment` 区域：
   - `Source` 选择 `Deploy from a branch`（从分支部署）
   - `Branch` 选择 `main`，旁边文件夹选 `/ (root)`
   - 点 `Save`（保存）
4. 等 1~2 分钟 → 刷新这个页面 → 顶部会出现蓝底提示：
   `Your site is live at https://你的用户名.github.io/run-checkin/`
5. **复制这个网址**，电脑浏览器打开验证能看到打卡页面 → 成功！🎉

## 第 2 步（手机）：在微信里用起来

### 2.1 把网址发到微信

任选一种：
- **电脑登录微信** → 把网址发到「文件传输助手」（自己发给自己）
- 或**手机浏览器**打开网址 → 复制网址 → 微信里粘贴发给「文件传输助手」

### 2.2 在手机微信里打开

1. 手机微信 → 点开「文件传输助手」→ 点你发的网址
2. 第一次打开如果提示「**非微信官方网页，请确认是否继续访问**」→ 这是正常提示，点「**继续访问**」即可
3. 看到打卡页面 → 成功！

### 2.3 收藏 / 置顶（以后每天从这里进，必做）

**方式一：收藏**
打开打卡页面 → 点右上角「···」→ 点「收藏」
以后每天：微信 → 右下角「我」→ 「收藏」→ 点开「跑步打卡」

**方式二：置顶聊天（更顺手，推荐）**
微信聊天列表 → 长按「文件传输助手」→ 点「置顶聊天」
以后每天：微信首页最上面就是它 → 点进去 → 点打卡链接

### 2.4 设置每天自动提醒打卡（免费，用微信自带功能）

1. 打开打卡页面 → 底部点「我的」→ 找到「打卡提醒」
2. 选好提醒时间（比如 20:30）→ 点「生成提醒消息」按钮
3. 页面提示"已复制" → 回到微信「文件传输助手」→ 长按输入框 → 「粘贴」→ 发送
4. **长按这条刚发的消息** → 弹出菜单点「提醒」→ 设时间 → 选「每天」重复 → 确定
5. 完成！以后微信每天这个点会响铃提醒你，点提醒就能跳到这条消息 → 点开链接打卡

> 💡 等以后你注册了微信小程序，我可以帮你把提醒升级成"订阅消息"——直接由小程序每天推送提醒卡片，体验更好（阶段二）。

## 每天的使用流程（30 秒搞定）

1. 微信 → 收藏/置顶 → 打开打卡页
2. 「今日打卡」→ 填跑步距离和时长（配速自动算）→ 保存
3. 顺手：体重输入一个数点「记录」；拍照一张正面照
4. 完事！日历、图表、照片会自动累计

**每周一次**：我的 → 导出备份 → 把备份文件发到「文件传输助手」留存（防止手机数据丢失）

## 常见问题 FAQ

| 问题 | 怎么办 |
|---|---|
| 微信提示「非微信官方网页」 | 正常现象，点「继续访问」 |
| 打开网址是空白页/404 | 部署刚生效，等 2 分钟再刷新；或检查上传的 zip 里有没有 index.html |
| 网址以 workers.dev 结尾，打不开 | 创建成了 Worker（不是网站）。重来：创建 → **点 Pages 标签** → 上传资产。正确的网址以 **pages.dev** 结尾 |
| 换新手机数据没了 | 数据存在旧手机的微信里。用旧手机：「我的」→ 导出备份 → 发到新手机微信 → 新手机打开页面「我的」→ 导入备份 |
| 拍照时没反应/黑屏 | 微信没给相机权限：手机设置 → 微信 → 相机 → 允许；再试 |
| 打卡页面点开是旧数据 | 确认用的是同一个网址、同一台手机 |
| Cloudflare 注册时收不到邮件 | 看看垃圾箱；或用 QQ 邮箱/163 邮箱重试 |
| GitHub 注册卡在人机验证 | 这是正常的防机器人验证，多试一两次，耐心按提示做 |
| 想换托管平台 | 数据导出备份后，换个平台部署同一份文件，导入备份即可，网址变了但数据在 |

# 🔑 密码重置指南（管理员操作）

> 适用场景：用户忘记密码，且系统暂未开放自助找回。
> 需要：Cloudflare API 令牌（具备 D1 Edit 权限）+ 本地 Node 环境。

## 方法一：使用重置脚本（推荐）

    node reset-password.js <用户名> <新密码>

脚本位置：C:\Users\Alwayso\Downloads\软件设计\reset-password.js

执行后：
1. 直接更新 D1 数据库中的密码哈希（PBKDF2-SHA256 10万次 + 16字节随机盐，与后端算法一致）
2. 强制清除该用户所有登录会话（所有设备需重新登录）
3. 输出新密码提示

## 方法二：让 AI 助手执行

直接告诉助手："把用户 xxx 的密码重置为 yyy"，助手会用上述脚本完成。

## 方法三：Cloudflare 控制台手动操作（了解原理用）

1. Cloudflare 后台 → Workers 和 Pages → D1 → run_checkin_db → 控制台
2. 执行 SQL（新哈希需本地用脚本计算，不要手写）：

    UPDATE users SET password_hash='<新哈希>', salt='<新盐>' WHERE username='<用户名>';
    DELETE FROM sessions WHERE user_id=(SELECT id FROM users WHERE username='<用户名>');

## 安全说明

- 重置会强制该用户重新登录（清空会话）
- 管理员（Cloudflare 账号持有者）可重置任何用户密码——这是当前设计接受的信任边界
- 生产环境建议后续接入短信/邮箱找回，减少人工干预
